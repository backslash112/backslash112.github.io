Privacy Policy - Quiz Video Uploader

Last updated: September 26, 2026

Quiz Video Uploader is a private tool used only by the owner of this site to upload and manage videos on the owner's own YouTube channels. It is not offered to the public.

Data it accesses

With the owner's consent through Google sign-in, the tool uses the YouTube Data API to upload videos, set titles, descriptions and thumbnails, and read the status of the owner's own videos and channels. It does not access any other Google data.

How data is stored and shared

OAuth tokens are stored only on the owner's own computer and server. No data is sold, shared with third parties, or used for advertising. The owner can revoke access at any time at myaccount.google.com/permissions.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
